Refresh

Hidden mode removes the "don't embed me" headers (X-Frame-Options, Content-Security-Policy) only from provider pages loaded inside this extension's invisible page, never in your tabs. That hidden copy runs without its CSP for a few seconds; see SECURITY.md. If a provider shows "page script never ran" in the results below, switch to the minimized window.

With background refresh off, data updates only when you visit a usage page yourself. Claude is fetched directly without opening a tab when possible.
