# TokenTracking 0.6.0-preview.3

Mac downloads are now **signed with Developer ID and notarized by Apple**, with the notarization ticket attached to each DMG.

This release keeps the menu bar customization, usage pacing and provider fixes from preview.2. No provider-reading behavior changes.

## Download and install

Choose `TokenTracking-0.6.0-preview.3-arm64.dmg` for Apple Silicon or `TokenTracking-0.6.0-preview.3-x64.dmg` for Intel. Requires macOS 13+ and Google Chrome. Node and the local service are included.

Quit TokenTracking, open the DMG and replace the app in Applications. Launch it from Applications. History, browser logins and preferences stay on your Mac. macOS may ask you to confirm opening an app downloaded from the internet.

If upgrading from an older local or ad-hoc build, macOS may treat the new signing identity as a new app for menu bar permission. Enable TokenTracking in System Settings → Menu Bar if needed.

For a first install, use **Open browser** to sign into each provider, then quit the dedicated Chrome window with **Cmd+Q**.

Verify your download using the matching `.sha256` file:

```sh
shasum -a 256 -c TokenTracking-0.6.0-preview.3-arm64.dmg.sha256
```

## Verification and remaining preview limits

Both packages pass signature verification, Apple notarization, DMG ticket validation and Gatekeeper assessment. The packaged Node runtime, SQLite and dashboard pass relocated-service smoke tests for Apple Silicon and Intel under Rosetta. All 54 regression tests pass.

Physical Intel Mac and fresh-Mac first-launch testing remain outstanding. Provider pages and endpoints are undocumented and may change. Live provider checks were not rerun for this packaging release; existing verification dates remain in `docs/PROVIDERS.md`.
