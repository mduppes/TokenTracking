# TokenTracking 0.6.0-preview.5

A guided first-run setup for Mac users.

- Choose the services you want to track.
- Sign in directly with each provider in TokenTracking’s separate Chrome profile.
- Clear privacy guidance: local history, read-only checks, no API keys or telemetry.
- Missing-Chrome help and pending connection states; Antigravity uses its running desktop app.
- Reopen setup from Settings → Service setup & privacy. Existing installs keep their settings and do not automatically show the wizard.
- Missing or non-executable Chrome produces a readable error without stopping the service.

Requires macOS 13+. Node and the local service are included; npm and developer tools are not required. Google Chrome is needed for browser services. Download the DMG for Apple Silicon or Intel, drag the app to Applications, then open it. Quit the previous app before replacing it; history and logins are preserved.

Both architectures use Developer ID signing and Apple notarization. Chrome’s unnecessary App Management request remains disabled. No live provider logins or usage were used for setup testing; fresh-Mac and physical Intel validation remain pending.
