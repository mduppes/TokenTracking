# TokenTracking 0.6.0-preview.2

Your AI subscription limits in your Mac menu bar, with more control over what you see and more reliable provider readings.

## What’s new

- Select and reorder your menu bar items, and choose which limit each service shows. Your preferences stay on your Mac.
- See how long until an exhausted limit resets, directly in the menu bar.
- Track ChatGPT’s 5-hour and weekly limits without duplicate or phantom usage meters.
- Track Antigravity’s three quota pools, including Gemini 4 Argon.
- More reliable Muse refreshes while it warms up, with old limit notices kept from replacing newer readings.
- Entering full-screen apps no longer opens a fallback window unexpectedly.
- Updated website, documentation and screenshots using demo data.

## Download and install

Choose `TokenTracking-0.6.0-preview.2-arm64.dmg` for Apple Silicon or `TokenTracking-0.6.0-preview.2-x64.dmg` for Intel. Requires macOS 13+ and Google Chrome. Node and the local service are included.

Open the DMG, drag TokenTracking into Applications and launch it. Use **Open browser** to sign into each provider, then quit the dedicated Chrome window with **Cmd+Q**. Enable TokenTracking in System Settings → Menu Bar if needed.

These are **ad-hoc signed previews, without Developer ID signing or Apple notarization**. If macOS blocks the first launch, attempt to open the app, then use System Settings → Privacy & Security → Open Anyway if you trust the build. Keep Gatekeeper enabled.

To update, quit TokenTracking before replacing it in Applications. History, logins and preferences are preserved. The upgrade removes previously recorded invalid OpenAI duplicate meters; valid session and weekly readings are retained.

Verify your download with the matching `.sha256` file, for example:

```sh
shasum -a 256 -c TokenTracking-0.6.0-preview.2-arm64.dmg.sha256
```

## Preview limitations

Provider pages and endpoints are undocumented and may change. Muse’s live warmup behavior remains under observation. Intel is cross-compiled on Apple Silicon; testing on a physical Intel Mac and fresh-Mac first launch checks remain outstanding. This release does not add API billing or token-count estimates.
